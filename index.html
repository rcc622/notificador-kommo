Privacy Policy - "Notificador de tareas para Kommo" (Chrome extension)

Last updated: October 9, 2026

"Notificador de tareas para Kommo" is a Chrome extension for people who work in a Kommo CRM account. It notifies the user when a task of the types they choose is assigned to them, lists those tasks in a side panel and highlights them inside the Kommo interface. It is not affiliated with or endorsed by Kommo.

Data the extension accesses

Using the session the user already has open in Kommo, the extension reads from the Kommo account the user is signed in to:

  • The account address (subdomain) and the ID of the logged-in Kommo user.
  • The list of task types of the account (names only), so the user can choose which ones to be notified about.
  • The tasks of the chosen types assigned to that user (text, due date, result).
  • The names of the leads those tasks belong to.

The extension does not read or store passwords, and does not access any other website.

How the data is used

Only to show the Chrome notification, the task list in the side panel, the pending-task counter on the extension icon, and to highlight tasks on the Kommo page.

Storage

The extension stores the account address, the task type names, the user's choice of task types and the IDs of tasks that were already notified, to avoid repeating notifications. This is kept locally in the browser (chrome.storage.local) and notified-task IDs are removed after 7 days. Uninstalling the extension deletes this data.

Sharing and transfer

No data is sent to the developer or to any third party. The extension only communicates with the user's Kommo account domain (*.kommo.com). It has no analytics, no advertising, and does not sell or transfer user data. It does not load or execute remote code.

Política de privacidad - «Notificador de tareas para Kommo» (extensión de Chrome)

Última actualización: 9 de octubre de 2026

«Notificador de tareas para Kommo» es una extensión de Chrome para quienes trabajan en una cuenta de Kommo. Avisa al usuario cuando se le asigna una tarea de los tipos que elige, lista esas tareas en un panel lateral y las resalta dentro de Kommo. No está afiliada ni respaldada por Kommo.

Datos a los que accede

Con la sesión que el usuario ya tiene abierta en Kommo, la extensión lee de la cuenta de Kommo en la que tiene sesión:

  • La dirección de la cuenta (subdominio) y el ID del usuario de Kommo con sesión iniciada.
  • La lista de tipos de tarea de la cuenta (solo nombres), para que el usuario elija de cuáles recibir aviso.
  • Las tareas de los tipos elegidos asignadas a ese usuario (texto, vencimiento, resultado).
  • Los nombres de los leads a los que pertenecen esas tareas.

La extensión no lee ni guarda contraseñas y no accede a ningún otro sitio web.

Uso de los datos

Únicamente para mostrar el aviso de Chrome, la lista de tareas en el panel lateral, el contador de pendientes en el icono y para resaltar las tareas en la página de Kommo.

Almacenamiento

Se guardan la dirección de la cuenta, los nombres de los tipos de tarea, la elección del usuario y los ID de las tareas ya avisadas, para no repetir avisos. Se guardan localmente en el navegador (chrome.storage.local) y los ID de tareas avisadas se eliminan a los 7 días. Al desinstalar la extensión se borran.

Transferencia a terceros

No se envía ningún dato al desarrollador ni a terceros. La extensión solo se comunica con el dominio de la cuenta de Kommo del usuario (*.kommo.com). No tiene analítica ni publicidad, y no vende ni transfiere datos de usuarios. No carga ni ejecuta código remoto.
